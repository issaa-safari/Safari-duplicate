Inline banner for form and page-level feedback (submit errors, save confirmations).

```jsx
<Alert variant="error">Please enter a valid email address.</Alert>
<Alert variant="success">Your quote request has been sent.</Alert>
```

Soft tint background + matching text color, no border. Use `error`/`success` for form outcomes, `warning` for caution notices, `info` (olive tint) for neutral tips.
